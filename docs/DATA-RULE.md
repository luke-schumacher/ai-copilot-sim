# The data rule

**Work only with data you create yourselves.**

## Yours

- Synthetic sessions from `claimcheck.synth` (in the lab repository)
- Your own simulator sessions
- Public data

## Everything else

- Do not use anything else, whoever offers it and however it reaches you.
- If something arrives anyway: do not open it, and tell Luke.
- If you are unsure whether something counts: ask before you open it.
- Do not commit recordings or real logger files. `.gitignore` blocks `*.vbo` and similar on
  purpose; do not work around it.
- A recording of a person (heart rate, camera) is personal data: ask Luke before recording anyone but yourself.
